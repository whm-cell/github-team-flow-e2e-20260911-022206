# GitHub Team Flow live integration sandbox

This disposable repository contains only synthetic classroom code and synthetic
test identities. It was created with the owner's authorization to verify the
Codex github-team-flow skill against real GitHub APIs and GitHub Actions.

Run `python3 -m unittest discover -s tests -v` to verify the enrollment-to-classroom
integration, permissions, repeat admission, class closure and replay access.

Test branches and PRs may intentionally contain defects or unmet dependencies.
Passing technical API checks is not evidence of independent human business review.
There is no production deployment, real student data or external database.
